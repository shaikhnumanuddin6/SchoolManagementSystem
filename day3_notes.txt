------------------------------------------------------------

The Admin Dashboard was upgraded from a basic statistics page
to a real database-driven dashboard.

The dashboard now displays:

- Total Students
- Total Teachers
- Total Classes
- Today's Attendance Percentage
- Present Today
- Absent Today
- Late Today
- Total Attendance Records Today
- Average Grade Percentage
- Total Grades

- Number of students in each class
- Present / Absent / Late count for each class

- 20 classes
- 50 classes
- 100+ classes

The same dynamic approach is used for students and teachers.
